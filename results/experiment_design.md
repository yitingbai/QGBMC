# QGBMC 从零最小证据重跑设计

## 1. 研究问题与可证伪假设

本实验不以复刻原稿表格中的具体数字为目标，而是从零检验原稿最核心、且与审稿意见直接相关的实验结论。研究问题是：在训练阶段不使用真实标签选择参数的完整多视图聚类中，基于局部拓扑熵的质量分数能否稳定地区分可靠视图与受污染视图，并通过质量相关的梯度调制和选择性对齐，提高聚类表现与噪声鲁棒性。

核心假设 H1 是，在至少两个真实多视图数据集上，完整 QGBMC 的平均 ACC、NMI 或 ARI 至少有一个指标优于不使用质量差异的 uniform-quality 控制，并且改进方向在三个随机种子上基本一致。核心假设 H2 是，在受控污染增强时，观测质量分数随污染程度总体下降，完整方法相对于拼接 KMeans 和 uniform-quality 控制的性能下降更缓。核心假设 H3 是，真实质量分数优于 shuffled-quality 控制；如果打乱后的分数与真实分数等效，则不能把收益归因于质量估计。规模假设 H4 仅检验工程可运行性：QGBMC 能在十万级多视图数据上完成训练和聚类，并给出时间与峰值显存；它不预设必须获得最优性能。

这些假设允许失败。若完整方法不优于 uniform 或 shuffled 控制，论文必须放弃“quality score 是主要有效机制”的结论。若优势只在使用标签挑选参数时出现，原稿的无监督性能结论不成立。若 0.9 污染率下仍出现异常高性能，则必须首先排查污染单位、剩余干净视图和实现强度，不能直接解释为模型鲁棒。

## 2. 数据集

完整的数据来源、文件哈希和转换边界见 `data_contract.md`。主数据集是 Caltech101-20。它来自 COMPLETER 官方仓库，包含 2,386 个样本、6 个明确的特征视图和 20 个类别，适合同时运行 QGBMC、简单基线和审稿人指定的 COMPLETER。第二个数据集是 Scene-15，包含 4,485 个样本，检查结论是否只存在于一个数据集。第三个数据集是 ALOI_1K，包含 110,250 个样本、4 个视图和 1,000 类，用于回应大规模数据要求。

本次不使用原稿中的 MNIST 和 CIFAR-10。原因不是回避审稿意见，而是现有材料没有提供其 3 视图和 4 视图的可追溯构造过程。使用来源清楚的真实多视图数据，比重新猜测特征提取器或用随机投影制造视图更符合复现要求。若作者以后提供原始构造脚本，这两个数据集可作为独立追加实验，不影响当前协议。

多视图聚类采用转导式设置：全部无标签特征参与训练，标签只在训练完成后计算外部评价指标。每个视图单独 z-score 标准化。所有统计量随运行保存。数据转换程序显式指定 MATLAB cell-array 键和标签键，不根据矩阵形状自动猜测转置。

## 3. 方法与基线

第一类是简单下界。`Concat-KMeans` 将标准化视图拼接后运行 KMeans；它检验深度方法是否超过最简单的早期融合。大规模 ALOI_1K 使用 MiniBatchKMeans，避免把聚类后处理误判为模型 OOM。

第二类是审稿人指定的直接竞争方法 COMPLETER，使用 CVPR 2021 官方仓库提交 `624dd9f...`。在 Caltech101-20 和 Scene-15 上使用完整视图设置。若旧版 PyTorch 代码在当前环境需要兼容性修改，所有修改形成补丁，不能改变损失函数、网络宽度或官方训练预算。

第三类是 QGBMC 及其机制控制。`full` 使用观测质量分数驱动 QGM 和 SCA。`uniform_quality` 保留网络、QGM 和 SCA，但令各视图质量均为 1，隔离“质量差异”本身。`shuffled_quality` 在每个 batch 内对视图质量分数做固定种子置换，保留分数分布但破坏分数与视图的对应关系。原有 `wo_qgm` 和 `wo_sca` 作为模块级补充消融，不代替质量分数隔离实验。

所有方法共享同一输入文件、标准化和评价代码。QGBMC 主配置在正式运行前固定，不针对数据集按 ACC/NMI/ARI/PUR 搜索。COMPLETER 使用其官方配置，并将不同预算作为方法固有设置明确报告。

## 4. 指标

性能指标为 ACC、NMI、ARI 和 PUR，方向均为越高越好。ACC 采用 Hungarian matching；NMI 使用 arithmetic normalization；ARI 允许出现负值。每个结果报告三个随机种子的均值和样本标准差，并保留每个种子的原始值。

鲁棒性指标包括各污染率下的四项聚类指标、相对干净条件的性能下降，以及污染率与质量分数之间的单调趋势。工程指标包括每次运行的 wall-clock time、CUDA 峰值显存、batch size、退出状态和异常信息。对于 OOM，整次运行标记失败，不能只将四个聚类指标中的一个写成 O/M。

## 5. 实验协议

正式最小实验使用随机种子 0、1、2。QGBMC 的隐藏层、潜在维度、学习率、batch size、质量阈值和损失权重在第一次正式运行前冻结。标签不参与早停或模型选择。为了避免用测试标签挑选 epoch，固定训练轮数；若出现数值发散，只按预先规定的有限值检查判为失败，不换参数追求更高 ACC。

噪声实验在 Caltech101-20 上进行。元素级污染把指定视图中按 Bernoulli 掩码选中的标准化特征替换为标准高斯值；样本级污染把指定视图中选中的整行替换为标准高斯向量。污染率使用 0、0.3、0.6、0.9。所有受污染视图、掩码和随机种子都保存在运行目录。该定义使“0.9”具有清楚含义，并允许解释仍保留的干净视图为何可能维持一部分聚类信号。

执行顺序遵循最便宜的证伪测试优先。先在 Caltech101-20 上运行 full、uniform 和 shuffled；只有真实质量分数显示稳定优势，才运行完整噪声网格、COMPLETER 和 ALOI_1K。这样可以在核心机制失败时及时停止，避免为了维持原结论继续消耗算力。

## 6. 消融与诊断

| 实验 | 保留内容 | 改变内容 | 检验的问题 |
|---|---|---|---|
| full | 全部结构 | 无 | 完整方法表现 |
| uniform_quality | QGM/SCA/参数量 | 所有质量分数固定为 1 | 是否需要质量差异 |
| shuffled_quality | 质量分布、QGM/SCA | 打乱分数与视图对应 | 分数是否真正识别对应视图 |
| wo_qgm | VQE/SCA | 不缩放梯度 | 梯度调制的增量作用 |
| wo_sca | VQE/QGM | 使用普通双向 InfoNCE | 选择性对齐的增量作用 |

质量诊断另外输出每个 epoch、每个视图的质量和调制值。诊断不以标签为依据。预期的最低行为是，在污染增强时受污染视图的质量总体下降；若不下降，即使最终 ACC 偶然较高，也不能宣称 VQE 正确识别了噪声。

## 7. 风险、限制与预算

COMPLETER主要针对不完整多视图问题，在完整视图设置下属于审稿人指定的参考而非完全同任务方法。ALOI_1K 验证十万级规模，但不能替代所有大规模数据集，也不能被写成 YTF50。三个种子是返修最小证据量，若标准差较大，最终稿应扩展到五个种子。固定参数避免标签泄漏，但可能牺牲每个数据集的最优性能；这是无监督公平性与最佳表格数值之间的必要取舍。

当前硬件为单张 NVIDIA RTX 4090 24GB。预算上限设为约 20 GPU 小时：代码和数据 smoke test 不超过 0.5 小时；Caltech101-20 与 Scene-15 的三种质量控制、三个种子预计 4 小时以内；噪声网格预计 6 小时以内；COMPLETER 两个数据集三个种子预计 4 小时以内；ALOI_1K 的 full 与简单基线预计 5 小时以内。所有实际耗时替换这些估计并写入结果。若 ALOI_1K 超出预算，首先减少训练轮数并将其限定为规模/资源实验，不使用单个最优种子冒充稳定性能结论。
